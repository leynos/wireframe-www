Common Signal·A Rust router for binary protocols

What we connect, we should understand.

wireframe is an experimental Rust library for building servers and clients for frame-based binary protocols. Frame the bytes, route messages by ID, and keep protocol behaviour open to inspection.

Get startedRead the guides

0.4.0-alpha1 is an alpha that is not yet published. It was targeted for 15 November 2026 and is not on crates.io yet. Interfaces may change before 1.0, so pin the exact version.

A common foundation for unfamiliar traffic. Every protocol brings its own rules. wireframe provides the framing and routing machinery, so an application can concentrate on the messages it handles.

Frame. Route. Handle.

Follow the message. A codec identifies frame boundaries. The routing layer selects a handler by message ID. Middleware surrounds the application work. The reply retraces the way it came, and the architecture guide explains each boundary.

Fragment reassembly is a transport step and optional. Message assembly, for protocols that spread one message across several frames, is a separate step that runs after it.

The stack, layer by layer

  1. Input

    Bytes off the socket

    A Tokio TCP stream. The server reads first, under a 10-second deadline by default: a preamble if it expects one, otherwise the first byte.

  2. Framing

    Cut at the length prefix

    A FrameCodec decodes frames. The default reads a 4-byte big-endian length prefix and refuses frames over 1,024 bytes.

  3. Envelope

    Read the envelope

    The serializer decodes an Envelope: a message ID, an optional correlation ID, and the payload bytes. Trailing bytes are a decoding error.

  4. Reassembly Optional

    Fragments, rejoined

    With fragmentation enabled, fragments arrive inside envelopes and are rejoined before routing, bounded by size, by count, and by time.

  5. Deflection

    Route by message ID

    One handler per ID. An ID with no route is logged and dropped; registering an ID twice fails at setup.

  6. Modulation

    Wrap the handler

    The route’s middleware wraps its handler, so it sees the request on the way in and the reply on the way out.

  7. Dwell

    Handle the message

    The handler runs with the envelope it was sent. It returns nothing; the default reply echoes the payload.

  8. Retrace

    Serialize, frame, send

    The reply keeps the request’s correlation ID and leaves through optional fragmentation, the serializer, the codec’s wrapper, the before_send hook, and the encoder.

What it carries

Any wire format, one trait

FrameCodec describes any wire format: how to cut frames, where the payload sits, and where a correlation ID lives.

  • Hotline20-byte header, big-endian lengths, a transaction ID
  • MySQL3-byte little-endian length, 1-byte sequence number
  • RESPTyped lines: simple strings, integers, bulk strings
00 00 00 0c12 payload bytes …

The default frame: a 4-byte big-endian length, then the payload. The three codecs above ship as worked examples.

Answer in middleware

A Transform wraps every route’s handler. Setup and teardown hooks carry per-connection state.

Push and streams, as parts

Priority push queues, a fair connection actor, and multi-frame responses. Tested, and not driven by WireframeServer in this alpha; main has since wired streaming responses.

One definition, both ends

WireframeClient correlates replies, reads streams, and pools reusable sockets, each opened on first use.

Test at the frame

Feed frames one byte at a time, fragment a payload, or pace a slow reader under paused time.

Large messages, bounded

Fragmentation, message assembly, and per-connection memory budgets that count fragment and assembly bytes together, slow reads at 80%, and close the connection past the cap.

Proposed · RFC 0007

Capacity is part of the design. A message leaving a queue has not necessarily left memory. The proposed budget contract accounts for retained data and admitted work by scope. Review the proposal

Already carrying traffic

mxd, df12’s Hotline server, depends on wireframe 0.3.0. Its transport adapter frames and routes the Hotline protocol; its domain crate never imports wireframe. Hotline’s framing ships with wireframe too, as a worked codec example.
