Worked examples

The wireframe repository ships ten runnable examples at v0.3.0. mxd, a complete Hotline server, is the full-size one.

wireframe 0.3.0 · samples verified 2026-10-31

Run them from a checkout of the release tag. Its lockfile pins dependencies that build, and its toolchain file names the nightly Rust it was tested with, which rustup installs on first use. Each example needs the examples feature.

  • Routing

    echo.rs

    The smallest server: one route, and the default reply echoes each envelope back. It listens on 127.0.0.1:7878 and stops on Ctrl+C.

  • Client

    client_echo_login.rs

    Sends a typed login request inside an Envelope to the echo server and decodes the acknowledgement. Start echo first.

  • Middleware

    ping_pong.rs

    Typed Ping and Pong messages, with a Transform that maps one to the other and a logging layer around it. The pattern this site’s samples follow.

  • Routing

    packet_enum.rs

    An enum of packet variants, with handlers dispatched on the variant received and containers such as HashMap in the payload.

  • Routing

    metadata_routing.rs

    Routing from a small frame header that carries the message ID and flags.

  • Codec

    hotline_codec.rs

    Hotline framing: a 20-byte header with big-endian lengths and a transaction ID. The protocol mxd speaks.

  • Codec

    mysql_codec.rs

    MySQL framing: a 3-byte little-endian payload length and a 1-byte sequence number.

  • Codec

    resp_codec.rs

    A minimal parser and encoder for a subset of the Redis serialization protocol: simple strings, integers, and bulk strings.

  • Streaming

    async_stream.rs

    Builds a Response::Stream of five frames with the async-stream crate, ready for a ConnectionActor to consume.

  • Streaming

    multi_packet.rs

    Splits a transcript across frames sent through a bounded channel by two producer tasks, with back-pressure keeping them in step with the consumer.

mxd: a whole server

mxd, the Marrakesh Express Daemon, is df12’s Hotline server in Rust, and it runs on wireframe 0.3.0. Its mxd-wireframe-server binary frames, routes, and answers Hotline transactions through wireframe, behind a transport adapter: the domain crate does not import wireframe, so transport types never reach the domain.

How mxd is put together

Binary protocols. Clear routes. A Rust library from df12 Productions, Edinburgh.
